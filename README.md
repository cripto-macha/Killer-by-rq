#  Bot - CC Killer Project

A Telegram bot that runs multiple card-testing modules against 6 different payment gateways.

## Features

- 6 payment gateways supported:
  - PayPal
  - Stripe
  - Square
  - Authorize.Net
  - Braintree
  - SSLCommerz
- Single-card input per command
- Admin panel for user management
- Access control (allowed users only)
- All killers embedded in a single file
